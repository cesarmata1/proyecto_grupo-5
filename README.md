# Proyecto Grupo 5 — Sistema de Gestión de un Restaurante

## Descripción
Proyecto final de la asignatura Programación en Python del Máster Universitario en Inteligencia Artificial y Ciencia de Datos.

El objetivo es desarrollar una aplicación de consola para gestionar un restaurante durante el servicio.

## Funcionalidades
- Cargar los datos del restaurante desde un archivo JSON.
- Cargar grupos de clientes y asignarles mesas.
- Tomar pedidos y validar los platos del menú.
- Calcular cuentas, cobrar y liberar mesas.
- Añadir platos y actualizar sus precios.
- Consultar la ocupación, las mesas activas y las ganancias.
- Implementar una funcionalidad original.

## Estructura del proyecto
- `main.py`: menú principal de la aplicación.
- `restaurante.py`: gestión de mesas, pedidos y cobros.
- `datos.py`: lectura y escritura de archivos JSON.
- `restaurante.json`: datos y menú del restaurante.
- `.gitignore`: archivos que Git debe ignorar.
- `mesas/`: archivos con grupos de clientes.
